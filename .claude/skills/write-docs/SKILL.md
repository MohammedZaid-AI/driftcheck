---
name: write-docs
description: Use when writing the README, demo script, limitations or the message to Scalio.
---
1. Write in simple English with short sentences.
2. No dashes or hyphens in sentences, no brackets, no decorative quotes, and no AI sounding phrases.
3. Show the problem first, then the tool, then the measured numbers.
4. Every number must come from reports/eval_report.json.
5. Link the public review sources for the problem.
6. Never claim the tool improved Scalio's real app. Say it was tested on this dataset.
